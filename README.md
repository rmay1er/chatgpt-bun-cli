# ChatGPT CLI (Bun)

Простая консольная утилита для взаимодействия с OpenAI через командную строку, собранная с помощью Bun.

## Возможности

- Ввод запросов к ChatGPT прямо из терминала
- Безопасный ввод API-ключа OpenAI (с маскировкой)
- Просмотр файлов в текущей директории
- Поддержка прерывания работы (Ctrl+C)

## Установка

### Вариант 1: Использование готового бинарника

1. Скачайте бинарник `mycli` из репозиторя, в папке `dist`
2. Сделайте файл исполняемым:
   ```bash
   chmod +x mycli
   ```
3. Запустите:
   ```bash
   ./mycli
   ```

### Вариант 2: Сборка из исходников

1. Установите [Bun](https://bun.sh/)
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-репозиторий.git
   cd chatgpt-bun-cli
   ```
3. Установите зависимости:
   ```bash
   bun install
   ```
4. Соберите бинарник:
   ```bash
   bun run compile
   ```
5. Запустите:
   ```bash
   ./mycli
   ```

## Получение API-ключа OpenAI

1. Перейдите на [OpenAI Platform](https://platform.openai.com/)
2. Войдите в свой аккаунт или зарегистрируйтесь
3. Перейдите в раздел "API Keys"
4. Нажмите "Create new secret key"
5. Скопируйте ключ (начинается с `sk-`)
6. Вставьте ключ при первом запуске программы

⚠️ **Важно:** Никому не передавайте свой API-ключ!

## Использование

После запуска программы:
1. Введите ваш API-ключ OpenAI (будет скрыт звездочками)
2. Вводите запросы к ChatGPT
3. Доступные команды:
   - `files` - показать файлы в текущей директории
   - `exit` - завершить работу

Для выхода также можно использовать Ctrl+C.
